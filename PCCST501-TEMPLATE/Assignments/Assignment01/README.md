# Assignment
Module 1: PCCST501 – Computer Networks

## Title
How the Internet Delivers a Web Page (www.google.com)

## Objective
To briefly explain the web page delivery process (TCP/IP, DNS, HTTP, TCP, cookies) when a user loads Google.

## Solution
Documented the stages of loading Google: DNS resolution, TCP handshake, and the HTTP GET/response cycle. Included diagrams for the TCP/IP stack and communication flow, plus an HTTP vs. FTP comparison.

## Output
A 4-page PDF report (`Assignment1 Report.pdf`) containing explanations, two diagrams, and a table.

## Conclusion
Application-layer protocols (HTTP, DNS, FTP) seamlessly deliver web content reliably, forming the foundation of everyday Internet use.

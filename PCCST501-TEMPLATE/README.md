# Assignment 
Assignment 3


## Title
PCCST501 - Computer Networks
Assignment 3: Data-Link Layer, Ethernet and Wireless LANs

## Objective
To analyze how the data-link layer provides framing, MAC addressing and shared-media access, with emphasis on Ethernet, wireless LANs and Mobile IP.

## Solution
Each question is answered with theory, diagrams and tables covering the data-link layer, the Ethernet frame, switch MAC learning, hub/switch/bridge, CSMA/CD and CSMA/CA, a lab WLAN design, Mobile IP, and a wired vs 802.11 frame comparison.

## Output
5-page PDF with an Ethernet frame diagram, a switch forwarding-table example, a WLAN topology, a Mobile IP flow diagram and comparison tables, with no Wireshark captures since Q3 was skipped.

## Conclusion
conclusion: Switched full-duplex Ethernet has made CSMA/CD largely unnecessary, while wireless needs CSMA/CA and a richer 802.11 frame, and Mobile IP keeps connections alive when a device changes networks.
